## Ce qu'il vous faut avant de commencer

- **Avoir 18 ans ou plus.** Les paris sont interdits aux mineurs.
- **Un numéro ivoirien actif**, au format +225 suivi de 10 chiffres, pour recevoir les codes par SMS.
- **Une pièce d'identité valide** : carte nationale d'identité, passeport ou permis de conduire.
- **Un compte mobile money à votre nom**, chez Orange Money, MTN MoMo, Moov Money ou Wave. Un retrait vers le compte d'une autre personne peut être refusé.

## Les 4 façons de s'inscrire sur 1xBet

| Méthode | Ce qu'on vous demande | Pour qui |
|---|---|---|
| Par téléphone | Numéro de téléphone et code de confirmation reçu par SMS | La méthode la plus simple pour la plupart des parieurs |
| Par e-mail | E-mail, mot de passe, nom, prénom, téléphone | Si vous voulez recevoir les justificatifs par e-mail |
| En un clic | Pays et devise (FCFA) ; 1xBet génère un identifiant et un mot de passe | Pour ouvrir un compte très vite, à compléter ensuite |
| Réseaux sociaux | Connexion via Google, Telegram ou X | Si vous voulez éviter de retenir un mot de passe de plus |

Quelle que soit la méthode, le compte est le même ensuite. Vous devrez de toute façon compléter votre profil avant de retirer vos gains.

## Inscription 1xBet par téléphone, étape par étape

1. Ouvrez 1xbet.ci ou l'[application 1xBet](/1xbet-apk/), puis touchez « Inscription ».
2. Choisissez l'onglet « Par téléphone ». Le pays (Côte d'Ivoire) et la devise (FCFA) sont normalement déjà remplis : vérifiez-les, car la devise ne peut plus être changée ensuite.
3. Entrez votre numéro, puis touchez « Envoyer le code ».
4. Recopiez le code reçu par SMS.
5. Saisissez le code promo si vous en avez un. Il ne pourra pas être ajouté plus tard. Le détail du bonus est sur notre page [code promo 1xBet](/code-promo-1xbet/).
6. Acceptez les conditions, confirmez que vous avez plus de 18 ans, puis validez.

### L'inscription en un clic : à noter absolument

C'est la méthode la plus rapide, et aussi la plus risquée si vous allez trop vite : l'identifiant et le mot de passe générés ne s'affichent qu'une fois. Enregistrez-les tout de suite, par une capture d'écran ou avec l'option de sauvegarde que propose 1xBet. Ajoutez ensuite votre numéro de téléphone dans le profil, pour pouvoir récupérer le compte en cas d'oubli.

## Inscription complète : profil et vérification d'identité

Un compte qui vient d'être créé permet de déposer et de parier. Pour retirer, 1xBet exige un profil complet et une identité vérifiée.

**1. Complétez le profil** (Mon compte → Profil personnel) : nom et prénom exactement comme sur votre pièce d'identité, date de naissance, adresse, e-mail et téléphone confirmés.

**2. Envoyez vos documents** dans la rubrique de vérification :

| Document | Exemples acceptés | Format |
|---|---|---|
| Pièce d'identité | CNI, passeport ou permis de conduire, en cours de validité | Photo nette des 4 coins, JPEG, moins de 5 Mo |
| Justificatif de domicile | Facture CIE ou SODECI de moins de 3 mois | Photo ou scan lisible |

## Se connecter à son compte 1xBet

Sur le site ou dans l'application, touchez « Se connecter », puis entrez :

- votre **numéro de compte (ID)**, votre **e-mail** ou votre **numéro de téléphone** ;
- votre mot de passe.

Si vous vous êtes inscrit via Google ou Telegram, utilisez le même bouton pour vous reconnecter.

**Mot de passe oublié ?** Touchez « Mot de passe oublié » et recevez un lien ou un code par SMS ou par e-mail. Si vous vous êtes inscrit en un clic sans ajouter de téléphone ni d'e-mail, seul le support peut vous aider. Ayez votre numéro de compte sous la main.

**Sécurisez le compte.** Activez la double authentification dans les paramètres. L'application 1xBet la propose : un code vous sera demandé à chaque nouvelle connexion.

## Problèmes fréquents à l'inscription

| Problème | Solution |
|---|---|
| Le SMS de confirmation n'arrive pas | Vérifiez le format du numéro (+225, puis 10 chiffres), attendez 2 minutes, puis redemandez un code. Vérifiez que votre téléphone reçoit bien les SMS. |
| « Accès refusé ! » à l'ouverture du site | Désactivez votre VPN. 1xBet bloque les connexions depuis les pays où il n'est pas autorisé. |
| Le numéro est déjà utilisé | Un compte existe déjà avec ce numéro. Utilisez « Mot de passe oublié » plutôt que d'en créer un nouveau. |
| Le code promo n'a pas été pris en compte | Le code ne s'ajoute pas après l'inscription. Contactez le support avec votre ID, sans créer de second compte. |

1xBet n'autorise qu'un compte par personne. Ouvrir un deuxième compte, même pour un nouveau bonus, peut entraîner le blocage des deux.

## Fermer ou suspendre son compte 1xBet

Pour fermer votre compte ou faire une pause, écrivez au support depuis le chat du site ou à **info-fr@1xbet-team.com**, avec votre numéro de compte. Vous pouvez demander une fermeture définitive ou une auto-exclusion temporaire. Retirez votre solde avant de faire la demande.
