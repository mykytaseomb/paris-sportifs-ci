2. Suivez votre progression dans la rubrique « Promo » ou dans le détail du solde bonus.
3. Une fois les 5 tours atteints dans les 30 jours, le montant restant passe sur votre compte principal.
4. Faites vérifier votre identité, puis demandez votre retrait sur le portefeuille mobile money qui a servi au dépôt.
