Tous les sites qui acceptent Wave acceptent aussi Orange Money. C'est utile en cas de panne : gardez les deux portefeuilles configurés pour ne jamais rester bloqué avant un match.

## Comment déposer avec Wave

1. Connectez-vous et ouvrez la rubrique **Dépôt**.
2. Choisissez **Wave**.
3. Saisissez le montant en FCFA et, si le site le demande, votre numéro Wave.
4. Confirmez le paiement dans l'**application Wave** : selon le site, une demande s'y affiche ou un code QR est à scanner.
5. Le solde de votre compte de paris est crédité en quelques instants.

Le paiement se valide toujours dans l'application Wave, jamais sur une page web qui vous demande votre code. Un message WhatsApp qui propose de « recharger votre compte 1xBet par Wave » à un numéro personnel est une arnaque.

## Comment retirer vers Wave

1. **Faites vérifier votre identité avant le premier retrait** : CNI, passeport ou permis. C'est la cause la plus fréquente des retraits bloqués.
2. Ouvrez **Retrait**, choisissez Wave et le numéro qui a servi au dépôt.
3. Indiquez le montant et confirmez.

Le nom de votre compte Wave doit correspondre à celui de votre compte de paris. Un bonus encore en cours de mise peut bloquer le retrait des gains qui lui sont liés : vérifiez votre solde bonus avant de demander un retrait.

## Les erreurs qui bloquent un dépôt Wave

| Problème | Cause fréquente | Solution |
|---|---|---|
| Rien n'apparaît dans l'application Wave | Application pas à jour ou déconnectée | Mettez Wave à jour, reconnectez-vous, relancez le dépôt |
| Dépôt refusé | Montant sous le minimum du site | Vérifiez le minimum affiché dans la rubrique Dépôt |
| Solde Wave débité, compte de paris non crédité | Validation tardive ou incident réseau | Notez la référence Wave et écrivez au service client du site |
| Retrait refusé | Identité non vérifiée ou nom différent | Envoyez vos documents ; utilisez un compte Wave à votre nom |
