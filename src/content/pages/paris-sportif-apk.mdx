## Installer une APK en 5 étapes

1. Ouvrez le site officiel de l'opérateur dans Chrome, en tapant l'adresse vous-même.
2. Téléchargez l'APK depuis la rubrique consacrée aux applications.
3. Autorisez l'installation pour Chrome quand Android le demande : Paramètres → Applications → Accès spécial → Installer des applis inconnues.
4. Ouvrez le fichier téléchargé et lancez l'installation.
5. Désactivez l'autorisation une fois l'application installée, puis connectez-vous avec votre compte existant ou créez-en un.

## Reconnaître une fausse APK

| Signe | Ce que ça veut dire |
|---|---|
| Lien reçu par WhatsApp, Telegram ou SMS | Fichier impossible à vérifier, souvent modifié |
| « Version pro », « VIP », « hack » ou « modifiée » | Arnaque : aucune APK ne change les résultats |
| Demande de code mobile money dans l'application | Tentative de vol : un dépôt se confirme dans le menu de votre opérateur |
| Fichier très différent en taille de celui du site officiel | Fichier altéré : supprimez-le |
| Application « Betclic » ou autre marque sur Google Play, publiée par une société inconnue | Fausse application : les opérateurs ivoiriens ne passent pas par le Play Store |

## Les erreurs d'installation les plus fréquentes

| Problème | Solution |
|---|---|
| « Application non installée » | Une ancienne version est déjà présente, ou le téléchargement est incomplet. Désinstallez l'ancienne version et retéléchargez l'APK. |
| Espace insuffisant | Libérez de la place ou choisissez une version légère quand elle existe, comme 1xBet Lite. |
| L'application s'ouvre puis se ferme | Mettez à jour Android et l'application, puis redémarrez le téléphone. |
