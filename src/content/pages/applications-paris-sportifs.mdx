## Installer une application de paris sans risque

Les fausses applications de paris sont courantes : copies vendues sur WhatsApp, « versions pro », applis de « coupons gagnants ». Quatre règles évitent presque tous les problèmes :

1. Téléchargez l'APK depuis le site officiel de l'opérateur, tapé directement dans le navigateur, jamais depuis un lien reçu par message.
2. Sur iPhone, passez par l'App Store et vérifiez le nom de l'éditeur. Les fichiers IPA et « profils » proposés ailleurs contournent les contrôles d'Apple.
3. Autorisez l'installation pour Chrome seulement, le temps d'installer : Paramètres → Applications → Accès spécial → Installer des applis inconnues. Désactivez ensuite l'option.
4. Ne donnez jamais votre code secret mobile money dans un formulaire ou un message : un dépôt se confirme dans le menu de votre opérateur.
